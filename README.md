# TOURDY · 투어디

공부 시간을 기록하고, 쌓인 마일리지로 국내·세계 여행을 하는 타이머입니다.
PC·Mac·iPad·iPhone의 브라우저에서 사용하거나 홈 화면/바탕화면에 설치할 수 있는 PWA입니다.
**기기 간 기록 동기화는 아직 구현되지 않았습니다.** 현재 기록은 각 브라우저·설치 환경에 저장됩니다.

## 이번 변경

- 저장 실패를 숨기지 않고, 다시 저장하거나 현재 기록을 파일로 보관할 수 있는 안내를 표시합니다.
- 데이터를 바꾸기 전에 직전 정상 저장본을 보존합니다. 손상된 저장본은 복구 가능한 사본을 찾고, 원본은 별도로 보존합니다.
- 복구할 수 없는 원본을 빈 초기 데이터로 덮어쓰지 않습니다. 다른 창에서 변경된 상태를 감지한 경우에도 저장을 중단합니다. 이것은 기기 간 동기화 기능이 아닙니다.
- 실제 타이머로 공부한 시간이 누적 30분 이상이 된 **세션의 종료 시점**에 최고급 무료 여행 티켓 1장을 지급합니다. 중간 정지와 과목 변경 전후 시간을 합산합니다. 실행 중 30분을 넘어도 먼저 지급하지 않습니다.
- 휴식, 딴짓, 예시 데이터, 직접 추가한 기록은 티켓 조건에서 제외합니다. 기록을 수정해도 이미 지급·사용한 티켓을 다시 지급하지 않습니다.
- 티켓은 나중에 사용할 수 있고 국내 도시 또는 세계 국가 한 곳을 고를 수 있습니다. 사용 시 이동과 티켓 소모를 함께 저장하며, 저장 실패 시 둘 다 적용하지 않습니다. 공부 시간·보유 마일리지는 바꾸지 않습니다.
- 무료 세계 여행을 선택하면 국내 완주 여부와 관계없이 세계 여행을 엽니다. 우주·비밀 목적지는 기존 해금 조건을 유지합니다.
- 기존 이용자에게도 완료한 실제 공부 기록이 30분 이상이면 티켓 1장을 제공합니다.

내부의 자동 복구 사본은 같은 기기 저장 공간에 있습니다. 저장 공간 전체를 지우면 함께 사라지며, 클라우드 백업을 대체하지 않습니다. 기존 수동 복사·복원 화면은 유지하고 형식 검증을 보강했습니다.

## 소스 구조

빌드 도구나 프레임워크 없이 정적 파일로 배포합니다. `index.html`의 스크립트 순서를 유지해야 합니다. 기존의 공유 상태와 호출 순서를 보존하기 위해 일반 스크립트로 기능별 분리했습니다.

| 위치 | 역할 |
| --- | --- |
| `index.html` | 화면 구조와 스크립트 로딩 순서 |
| `css/app.css` | 기존 스타일과 보상·저장 안내 스타일 |
| `js/storage.js` | 저장, 검증, 최근 정상 사본, 손상 원본 보존 |
| `js/rewards.js` | 누적 30분 조건과 티켓의 지급·사용 상태 |
| `js/core.js` | 상태 초기화, 날짜·시간 집계, 저장 안내 |
| `js/timer.js` | 타이머, 예약·뽀모도로, 알림, PIP |
| `js/planner.js`, `js/stats.js`, `js/settings.js` | 기록·할 일·통계·설정 |
| `js/travel-*.js` | 국내·세계·우주 데이터와 지도·도착·업적 |
| `js/first-trip.js` | 무료 여행 선택 및 저장 트랜잭션 |
| `js/extras.js`, `js/app.js`, `js/pwa.js` | 추가 기능·화면 초기화·설치와 업데이트 |
| `sw.js` | HTML/CSS/JS/이미지를 함께 저장하는 오프라인 셸 |

저장 키 `studyplanner.v2`와 기존 데이터 필드는 유지했습니다. `studyplanner.v2.lastGood`은 직전 정상 사본, `studyplanner.v2.damaged`는 최근 읽지 못한 원본입니다. `firstTrip` 필드는 티켓의 `pending`/`ready`/`used` 상태를 보존합니다.

## 검증

Node.js 20 이상에서 의존성 설치 없이 실행합니다.

```sh
npm test
```

자동 테스트는 저장 공간 부족, 손상 복구, 이전 버전 기록 읽기, 다른 창의 변경 감지, 30분 경계, 실행 중 지급 보류, 중복 지급 방지, 무료 여행 저장 실패 시 원상 유지, 오프라인 셸 구성을 확인합니다.

화면을 확인하려면 이 폴더를 HTTP 서버로 열면 됩니다. GitHub Pages는 저장소 파일을 그대로 배포합니다. HTML·JS·CSS 변경 시 `sw.js`의 `VERSION`도 올려야 합니다. 업데이트는 새 셸 전체를 준비한 후, 사용자가 업데이트를 누르거나 기존 창을 모두 닫았을 때 적용됩니다.

실제 기기의 화면 잠금 중 알림, iOS 설치/업데이트, 장기간 사용과 저장 공간 삭제 동작은 별도 기기 검증이 필요합니다.
